Runsheet 
Event management, start to strike.

Runsheet is an event management system that keeps venue, budget, vendors, guest RSVPs, and day-of attendance in one place. It's built for event organizers who are currently juggling spreadsheets, email threads, and paper lists across a single event.

This repository currently contains the marketing landing page for the product.

1. Overview
1.1 Purpose

Runsheet helps event organizers plan and run events end to end — from the first budget line to the last guest checked in at the door.

1.2 Scope

The product is designed to let users:
Create and manage events (venue, date, capacity)
Track budget and vendor/staff contracts
Send invitations and collect RSVP responses
Run a live day-of timeline and check-in guests at the door
1.3 Target users
Event organizers
Administrators
Vendors and event staff
Invited guests
